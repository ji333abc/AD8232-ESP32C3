# STM32 OSC 示波器上位机

适用于 `OSC` 工程中的 STM32G030F6P 固件。Windows 上用 Python 3.10 或更新版本运行。

在本目录打开 PowerShell，然后运行以下命令。演示模式直接启动 1 kHz 正弦波，不占用串口，也不依赖 pySerial。

```powershell
py app.py --demo
```

连板时先安装串口依赖，再启动程序。关闭占用同一 COM 口的串口工具，选择示波器对应端口，点击「连接」。

```powershell
py -m pip install -r requirements.txt
py app.py
```

## 波形和测量

- 「暂停显示」冻结当前帧。继续显示时跳到最近收到的波形。
- 拖动图上的 A、B 游标来读取时间差和幅度差。频率根据当前帧的上升沿穿越幅值中点的间隔估算，至少需要两次这样的交越。
- 「应用」下发采样计数、增益档和耦合模式。「自动」调用板端自动设置。用「当前帧」一行查看板端实际采样参数。示波器上电的默认采样计数为 320，对应每点 10 µs。
- 纵轴默认使用 ADC 码。填写当前所选档位的斜率（V/码）后点「应用标定」。电压按 `V = (ADC 码 − 零点码) × 斜率` 换算。四档默认零点分别为 1817、1816、1803、1786 码，斜率由实测提供。可用已知输入电压变化除以对应的 ADC 码变化，保留符号。标定值在本次运行内有效，清空斜率并应用可返回 ADC 码。

## 串口协议

- `256000 8N1`，无流控。波形帧形如 `<Time00320+Fre32000+Amp0+DC+…>`。末段是 256 个连续的四位十进制采样，每个采样范围为 0–4095，没有分隔符。
- TIM1 的计数时钟为 32 MHz。采样间隔为 `Time / 32` µs。`Fre` 保留在解析结果中，界面显示从波形估算的频率。
- 固件发出 `<Get>` 后等待约 20 ms，再读取命令。上位机在串口线程收到 `<Get>` 时发送已排队的设置，例如 `<Time00320><Amp0><CoupDC>` 或 `<Auto>`。`Time` 命令的数字允许不补零。

协议取自 `OSC/Core/Wave/wave.c`、`OSC/Core/Message/msg.c`、`OSC/Core/Src/tim.c` 和 `OSC/Core/Src/usart.c`。
